它的样子

克制，是为了不打扰

🧭 常驻菜单栏

没有主窗口，只在顶部菜单栏放一个小图标，需要时才出现。

🔕 不抢焦点

弹窗不夺取键盘焦点、不自动消失，手头的事不被打断，随手点掉即可。

📂 本地 JSON 配置

所有提醒写在一个文件里，所见即所得。改完 ≤20 秒自动生效，无需重启。

🔊 柔和提示音

带全局开关，可在托盘菜单里随时切换。

🚀 开机自启

一键开启，登录即常驻，再也不用记得手动打开。

🤫 纯本地

无账号、无云同步、无后台上传。你的提醒只待在你自己的电脑上。

三类提醒，覆盖日常

每日定时 / 固定间隔 / 每年纪念日

daily

每天固定时间点

例：每天 14:00 写周报
interval

固定间隔循环

例：每 60 分钟起身动动
anniversary

每年某月某日

例：每年 06-15 的纪念日

安装

仅支持 Apple Silicon（M1 及以后）

下载 MacaBell_0.1.0_aarch64.dmg，双击打开，把 MacaBell 拖进「应用程序」。
首次打开若提示「无法验证开发者」或「已损坏」，是因为应用未做 Apple 付费签名 —— 在「应用程序」里右键点 MacaBell → 打开，再点一次「打开」即可。
顶部菜单栏出现 🍬 图标即成功。点它 → 测试提醒一下，右上角会滑入一个糖果色弹窗。
⌘ 还是打不开？打开「终端」执行一次：
xattr -dr com.apple.quarantine /Applications/MacaBell.app
这会移除系统给未签名应用加的隔离属性，之后正常双击即可。

怎么配提醒

首次启动会生成 ~/.macaron-reminder/reminders.json，用任意编辑器改它

{
  "soundEnabled": true,
  "reminders": [
    { "id": "work-report", "type": "daily", "time": "14:00",
      "title": "工作提醒", "message": "该写周报啦" },

    { "id": "sit-too-long", "type": "interval", "everyMinutes": 60,
      "title": "久坐提醒", "message": "起来动动，喝口水吧" },

    { "id": "anniversary", "type": "anniversary", "date": "06-15", "time": "09:00",
      "title": "纪念日", "message": "今天是个特别的日子" }
  ]
}
改完保存即可，无需重启 —— 后台每 20 秒读取一次最新配置。想加提醒就往数组里加一项，想停某条就删掉它。
